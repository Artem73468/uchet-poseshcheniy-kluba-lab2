# Учёт посещений клуба

## Описание проекта

Проект посвящён информационной системе **«Учёт посещений клуба»**.

Система предназначена для автоматизации учёта клиентов, абонементов и посещений клуба. Она должна хранить данные о клиентах, видах и сроках действия абонементов, датах и времени посещений и истории посещений каждого клиента.

## Цель проекта

Основная цель — автоматизировать учёт посещений клуба и упростить контроль за абонементами клиентов.

Система должна позволять:

- регистрировать приход клиента;
- проверять действительность абонемента;
- регистрировать посещение;
- просматривать историю посещений;
- выполнять поиск клиентов;
- формировать отчёты и статистику.

## Пользователи системы

| Пользователь | Основные возможности |
|---|---|
| Администратор клуба | Регистрация клиентов, оформление абонементов, регистрация посещений, поиск клиентов, отчёты |
| Клиент клуба | Просмотр своего абонемента и истории посещений |
| Руководитель клуба | Просмотр статистики и формирование отчётов |

## Архитектура

В предыдущей лабораторной работе для проекта была предложена клиент-серверная архитектура:

1. **Интерфейс пользователя** — приложение или веб-сайт.
2. **Серверная часть** — обработка запросов и основных операций.
3. **База данных** — хранение сведений о клиентах, абонементах и посещениях.

Для базы данных в предыдущей работе была указана **SQLite**, а в качестве среды разработки — **Visual Studio Code**.

## Сценарий регистрации посещения

1. Клиент приходит в клуб.
2. Администратор открывает систему.
3. Администратор находит клиента.
4. Система отображает информацию о клиенте.
5. Система проверяет абонемент.
6. При действующем абонементе администратор регистрирует посещение.
7. Система сохраняет дату и время посещения.
8. При ограниченном количестве посещений остаток уменьшается на единицу.
9. Пользователь получает сообщение об успешной регистрации.
