# Учёт посещений клуба

## Описание проекта

Проект посвящён информационной системе **«Учёт посещений клуба»**.

Система предназначена для автоматизации учёта клиентов, абонементов и посещений клуба.

Информационная система должна хранить следующие сведения:

- данные о клиентах;
- виды абонементов;
- сроки действия абонементов;
- даты и время посещений;
- количество оставшихся посещений;
- историю посещений каждого клиента;
- сведения о сотрудниках клуба.

Система позволяет упростить работу сотрудников клуба и обеспечить удобный контроль посещений и абонементов.

## Цель проекта

Основная цель проекта — автоматизировать учёт посещений клуба и упростить контроль за абонементами клиентов.

Система должна позволять:

- регистрировать клиентов;
- редактировать данные клиентов;
- оформлять абонементы;
- проверять действительность абонемента;
- регистрировать посещение;
- сохранять дату и время посещения;
- просматривать историю посещений;
- выполнять поиск клиентов;
- контролировать состояние абонементов;
- формировать отчёты и статистику.

## Пользователи системы

В информационной системе предусмотрены следующие роли пользователей.

| Пользователь | Основные возможности |
|---|---|
| Администратор клуба | Регистрация и редактирование данных клиентов, оформление абонементов, регистрация посещений, просмотр истории, контроль абонементов, формирование отчётов |
| Клиент клуба | Просмотр своего абонемента и истории посещений |
| Руководитель клуба | Просмотр статистики посещений, анализ количества клиентов и абонементов, формирование отчётов |

## Архитектура

В предыдущей лабораторной работе для проекта была предложена клиент-серверная архитектура.

Основные части системы:

1. **Интерфейс пользователя** — приложение или веб-сайт, через который пользователь взаимодействует с системой.
2. **Серверная часть** — обработка запросов пользователей и выполнение основных операций системы.
3. **База данных** — хранение сведений о клиентах, абонементах и посещениях.

Для хранения данных в предыдущей лабораторной работе была указана **SQLite**.

В качестве среды разработки используется **Visual Studio Code**.

- проверку срока действия абонемента;

- просмотр статистики посещений.

## Сценарий регистрации посещения

Основной сценарий работы системы — регистрация посещения клиента.

Последовательность действий:

1. Клиент приходит в клуб.
2. Администратор открывает информационную систему.
3. Администратор выполняет поиск клиента по имеющимся данным.
4. Система отображает информацию о найденном клиенте.
5. Система проверяет действительность абонемента.
6. Если абонемент действителен, администратор регистрирует посещение.
7. Система сохраняет дату и время посещения.
8. Если абонемент имеет ограниченное количество посещений, остаток уменьшается на единицу.
9. Система сообщает об успешной регистрации посещения.
